E-Commerce-Sales-Analysis
E-Commerce Sales Analysis using SQL and Google Sheets

Project Overview
This project analyzes e-commerce sales data to understand customer purchasing behavior, sales trends, seller performance, and delivery performance.

 Tools Used
- SQL Server
- Google Sheets
  

1. SQL Analysis
- Customer purchase frequency
- Repeat customer percentage
- Monthly sales trends and growth
- Average Order Value (AOV)
- Top-performing states, sellers, and products
- Delivery performance analysis

2.Google Sheets Dashboard
- Sales performance overview
- Key business metrics
- Customer and seller analysis
- Sales trends and visualizations

 SQL Concepts Used
- SELECT, WHERE, GROUP BY, ORDER BY
- JOINs
- Aggregate Functions
- CASE WHEN
- CTEs
- Subqueries
- Window Functions
- LAG()
- Date Functions

 Project Files
- `Ecommerce_Analytics_SQL.sql` – SQL queries
- `E-commerce_Dashboard.pdf` – Dashboard
- `E-commerce_Analysis.xlsx` – Excel analysis

## Conclusion
This project demonstrates how SQL and Google Sheets can be used to analyze e-commerce data and generate meaningful business insights.
